# EYFI Reward Ladder — Submission Notes

I created a responsive interactive reward ladder using HTML, CSS and vanilla JavaScript. I used AI to brainstorm the gamified “Campus Quest” concept and accelerate the first draft, then refined the milestone states, progress animation, mobile layout and reward-unlock interactions myself.

The prototype includes a slider, clickable milestones, live “next unlock” feedback, confetti on achievement and a one-click seven-second demo for recording the submission video.
